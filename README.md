# 学习通讨论题目采集自动回复 · 使用说明

> 脚本版本：v1.2.8  
> 作者：李优涵

---

## 一、这个脚本能干什么

在学习通的**课程讨论区**里，帮你：

1. **一次性复制全部讨论题目**，粘贴到 ChatGPT / DeepSeek / 通义千问等任意 AI 平台要答案
2. 把 AI 给出的**【答案N】格式的答案块**整段贴回来，脚本自动按编号对应到每道题
3. **自动逐条发布**到各个话题，中间自动跳过已回复的
4. 没来得及配答案的题，发一条固定兜底文案（默认「坚持自主创新」，可自定义）

脚本**只处理题目本身，不碰评论区**，也不会误抓别人的回复。

---

## 二、安装

1. 浏览器安装 **Tampermonkey**（油猴）或 Violentmonkey 扩展
2. 打开油猴管理面板 → **新建脚本**
3. 把完整代码粘贴进去 → **保存**
4. 访问学习通讨论区页面，右上角会自动出现脚本面板

**支持的学习通页面**：
- `groupweb.chaoxing.com/course/topic/*` （讨论区）
- `mooc2-ans.chaoxing.com/*` （课程主页）

---

## 三、界面总览

面板右上角，有 **4 个 Tab**：

| Tab | 作用 |
|-----|------|
| 📋 采集 | 抓取话题列表、复制题目 |
| ✍️ 答案 | 粘贴 AI 答案、保存到工作集 |
| 🚀 发布 | 自动逐条发布 |
| ⚙️ 更多 | 清除记录、查看日志 |

面板可以**拖动**到任意位置，位置会被记住。点标题栏的 `—` 可以收起。

## 四、标准操作流程

### 步骤 1：进入讨论列表页

打开学习通课程主页，**点一下顶部的「讨论」菜单**，或者直接访问讨论列表页。

如果面板里显示 **`📋 打开课程讨论列表页`** 按钮，说明脚本检测到你在课程主页，点一下这个按钮就能跳转过去（脚本会尝试自动帮你点「讨论」菜单）。

### 步骤 2：勾选要处理的题目

进入 **📋 采集** Tab：

- 看到话题列表后，**默认勾选所有未回复的题**（`✅` 表示已回复过，默认不勾）
- 也可以点 **「全选」** 或**手动勾选**要处理的题
- 统计行会显示 **`已选 X/Y`**

### 步骤 3：复制题目

点 **`📋 复制全部题目（勾选的）`** 按钮：

- 复制成功后按钮会变绿，显示 **`✅ 已复制 N 道题目`**
- 复制出来的文本格式是这样的：

```
以下是课程讨论题目。请逐题作答，答案要简短（每道题一般不超过 100 字）。
答案必须严格按以下格式输出，每段以【答案N】开头（N 与题目编号对应）……
题目如下：
【1】什么是计算机网络中的 IP 地址？
【2】简述操作系统的四大基本功能。
【3】……
```

### 步骤 4：把题目贴给 AI 平台要答案

打开 DeepSeek / ChatGPT / 通义千问 / Kimi 等任意 AI，把刚刚复制的整段文本粘进去，让它按格式作答。

AI 会返回类似：

```
【答案1】
IP 地址是分配给网络中每台设备的唯一标识，用于在网络中定位和通信。
【答案2】
操作系统的基本功能包括：进程管理、内存管理、文件管理、设备管理。
【答案3】
……
```

### 步骤 5：把答案贴回脚本

切到 **✍️ 答案** Tab：

- 点 **`📋 一键粘贴剪贴板内容`**，脚本自动读取剪贴板填进文本框
- 或者手动 `Ctrl+V` 贴到文本框
- 然后点 **`✔ 保存答案（解析并合并）`**

脚本会：
- 只认 `【答案N】` 段，多余文字忽略
- 把答案按编号写进工作集
- 日志里显示 `答案已保存：X/Y 题`

### 步骤 6：自动发布

切到 **🚀 发布** Tab，确认两个参数：

- **无答案时发**：没存答案的题发什么（默认「坚持自主创新」，清空则跳过）
- **回复间隔**：每两个话题之间的等待秒数（默认 30 秒）

然后点 **`🚀 自动发布（按工作集顺序）`**：

- 脚本会逐个打开话题 → 填答案 → 点发布 → 等间隔 → 下一个
- 中途想停，可以在话题页点 **`⏹ 停止自动发布并返回列表`**
- 如果中途关掉页面，重新打开列表页会看到 **`▶ 继续本轮任务`**，可以接着跑

## 五、各 Tab 详细说明

### 📋 采集

| 元素 | 说明 |
|------|------|
| 话题列表 | 每行一道题，前面有勾选框，`✅` 表示已回复过 |
| 全选 | 一键勾选/取消全部 |
| 统计行 | `共 X 个话题 · 已回复 Y 个 · 工作集 Z 题 · 已存答案 A/Z · 已选 B/X` |
| 复制按钮 | 把勾选的题整理成 AI 友好格式复制到剪贴板 |

### ✍️ 答案

| 元素 | 说明 |
|------|------|
| 顶部统计 | 同上 |
| 🔄 刷新 | 重新扫描页面、重读本地数据 |
| 📋 一键粘贴剪贴板内容 | 自动读取剪贴板填入文本框 |
| 🗑 清空输入框 | 只清文本框，不动已存答案 |
| 文本框 | 粘贴 AI 答案的地方 |
| ✔ 保存答案 | 解析【答案N】段并写入工作集 |
| ⚠️ 清除全部已存答案 | 清空工作集里所有题目的答案（二次确认） |

**注意**：
- 「清空输入框」和「清除全部已存答案」是两件事，别搞混
- 保存答案时会**全量覆盖**：新答案块里没有的编号，旧答案会被清掉
- 所以每次贴答案时最好**把该批全部答案一次贴进来**

### 🚀 发布

| 元素 | 说明 |
|------|------|
| 无答案时发 | 没存答案的题的兜底文案 |
| 回复间隔 | 两话题之间的等待秒数（建议 ≥ 30，太低易触发学习通风控） |
| 🚀 自动发布 | 开始批量发布 |
| ▶ 继续本轮任务 | 上次没跑完时出现，接着跑 |
| ⏹ 放弃本轮任务 | 清空队列，重新开始 |

### ⚙️ 更多

| 元素 | 说明 |
|------|------|
| 🧹 清除「已回复」记录 | 让所有话题变回「未回复」状态，可以重新发一遍 |
| 日志 | 本次会话的操作记录 |
| 最近操作记录 | 跨页面的操作历史 |

## 六、常见问题

**Q1：面板弹出两个？**  
刷新页面即可。如果仍然两个，检查油猴里是否装了两份同样的脚本。

**Q2：点「打开课程讨论列表页」跳到 404？**  
先手动点一下学习通顶部的「讨论」菜单，让页面加载出内嵌讨论区，再点脚本按钮。

**Q3：复制题目后清单里出现「话题 xxxxxx」这种没识别出标题的题？**  
这是脚本没抓准话题标题。展开清单核对，把没识别的题取消勾选，或者手动编辑后再复制。

**Q4：AI 返回的答案不是【答案N】格式？**  
在复制题目时的提示词里已经说明了格式要求。如果 AI 还是没按格式，可以手动改成 `【答案1】` `【答案2】` 这种格式，脚本只认这种标记。

**Q5：发布时提示「发布失败」？**  
- 间隔太短 → 提高回复间隔到 60 秒以上
- 有其他学习通页面/手机 App 在线 → 关掉其他端
- 答案太长 → 精简到 100 字以内

**Q6：想改「无答案时发」的文案？**  
在两个地方都可以改：🚀 发布 Tab 和话题详情页的发布区，改完立刻生效。

**Q7：中途关掉了浏览器，还能继续吗？**  
能。重新打开学习通讨论列表页，面板里会显示 **`▶ 继续本轮任务`**，会从上次停下的地方接着跑。

**Q8：脚本会不会重复发已经回复过的话题？**  
不会。已回复的话题会打 `✅` 标记，自动发布时直接跳过。如果你想重发，可以到 ⚙️ 更多 Tab 点「清除『已回复』记录」。

## 七、数据存在哪里

所有数据都保存在**浏览器本地（localStorage）**，包括：

- 工作集（题目 + 答案）
- 已回复记录
- 面板位置
- 日志

**不上传任何服务器**。换电脑或清浏览器数据会丢失。

导出的 `cxar_qa_*` 键：
- `cxar_qa_topics` — 工作集
- `cxar_batch_done_*` — 已回复标记
- `cxar_fallback` — 兜底文案
- `cxar_qa_interval` — 回复间隔

## 八、使用建议

1. **先用 5-10 道题试一遍**，确认整个流程通畅，再批量搞
2. **回复间隔别低于 30 秒**，学习通对频繁操作有风控
3. **一次只开一个学习通页面**，多个页面同时跑容易触发失败
4. **答案别太长**，100 字以内最佳，太长发布容易被截断
5. **保存答案前先看一眼日志**，确认解析出的题数对得上
